# Library System

A simple desktop Library Management System built with **Java**, **JavaFX**, and **Maven**.

## Features

* Manage books and library records
* Add, view, update, and delete data
* JavaFX graphical interface
* Local file-based data storage

## Requirements

* JDK 21
* Apache Maven

## Run

```bash
mvn clean compile
mvn javafx:run
```

Maven automatically downloads the required JavaFX dependencies.
